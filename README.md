# 🚀 Featured Projects

### 🌍 [Outly — Personalized Outing Planner](https://github.com/tecmeckc/Outly)

A full-stack personalized outing planner that helps users **discover,
plan, save, and shop for their trips — all in one place.**

Built using **React, Node.js, Express.js, PostgreSQL and Sequelize**.

- 🗺️ Personalized outing plans based on location, budget, time, group type and interests
- 📍 Smart place recommendation engine
- 🤖 AI-generated personalized itineraries
- 💰 Budget-aware planning
- 🔐 OTP-based authentication & JWT authorization
- 💾 Saved plans & search history
- 🏙️ Master city database
- 🛒 Travel essentials marketplace
- 💳 Razorpay payment integration
- 🧾 Cart, billing, checkout & order confirmation
